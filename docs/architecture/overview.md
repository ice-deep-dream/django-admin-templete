# 架构概览

## 整体架构

本项目采用 **前后端分离** 架构，后端提供 REST API 和管理后台，前端提供独立的单页应用。

```
┌─────────────────────────────────────────────────────────────┐
│                        客户端                                │
├──────────────────────┬──────────────────────────────────────┤
│   Django Admin       │         React SPA                     │
│   (管理后台)          │         (前端应用)                     │
│   Unfold UI          │         Vite + React 19               │
└──────────┬───────────┴──────────────┬───────────────────────┘
           │                          │
           │ HTTP/HTMX                │ HTTP/REST API
           │                          │ JWT Auth
           ▼                          ▼
┌─────────────────────────────────────────────────────────────┐
│                    Django Backend                            │
├──────────────────────┬──────────────────────────────────────┤
│   Django Admin       │         REST API                      │
│   Views              │         DRF ViewSets                  │
│   Unfold Components  │         JWT Auth                      │
└──────────┬───────────┴──────────────┬───────────────────────┘
           │                          │
           ▼                          ▼
┌─────────────────────────────────────────────────────────────┐
│                      数据层                                   │
├──────────────────────┬──────────────────────────────────────┤
│   SQLite/PostgreSQL  │         Cache (LocMem)                │
│   Django ORM         │         Session                       │
└──────────────────────┴──────────────────────────────────────┘
```

## 设计原则

### 1. 前后端分离

- 后端独立运行，提供完整的 REST API
- 前端独立开发，通过 API 与后端通信
- Django Admin 作为独立的管理界面

### 2. 组件化

- 后端：Unfold 组件系统，可复用 UI 组件
- 前端：React 组件，模块化设计

### 3. 可扩展

- Mixin 扩展机制
- 插件式第三方集成
- 动态配置支持

## 核心模块

| 模块 | 说明 |
|------|------|
| `unfold` | 管理后台 UI 框架 |
| `example` | 业务应用 |
| `example.core` | 核心工具模块 |
| `frontEnd/src/modules` | 前端业务模块 |
| `frontEnd/src/shared` | 前端共享模块 |

## 数据流

```
用户操作 → React 组件 → Zustand Store → API 调用 → DRF ViewSet → Django ORM → 数据库
                                                                    ↓
用户界面 ← React 渲染 ← Zustand 更新 ← JSON 响应 ← 序列化器 ← 查询结果
```

## 认证流程

```
登录请求 → 验证用户名密码 → 生成 JWT Token → 返回 Token
                                              ↓
后续请求 → 携带 Bearer Token → JWT 验证 → 通过/拒绝
```
