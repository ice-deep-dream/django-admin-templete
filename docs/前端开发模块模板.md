# 前端开发模块模板

> 基于 React + TypeScript + Vite + MUI + Zustand 的模块化前端架构规范

---

## 一、项目架构总览

### 目录结构

```
src/
├── shared/                    # 全局共享层
│   ├── api/                   #   API 客户端
│   │   ├── client.ts          #     axios 实例 + 拦截器
│   │   └── index.ts           #     统一导出
│   ├── components/            #   全局组件
│   │   ├── layout/            #     布局组件（PageLayout, DashboardLayout, Pagination）
│   │   ├── common/            #     通用组件（PermissionGuard, HasPermission）
│   │   └── index.ts           #     统一导出
│   ├── stores/                #   全局状态
│   │   ├── authStore.ts       #     认证状态
│   │   ├── layoutStore.ts     #     布局状态
│   │   └── index.ts           #     统一导出
│   ├── types/                 #   全局类型定义
│   ├── hooks/                 #   全局自定义 Hooks
│   ├── theme/                 #   主题配置
│   ├── utils/                 #   工具函数
│   └── data/                  #   全局 Mock 数据
│
├── modules/                   # 业务模块层（feature-based）
│   └── {module}/              #   模块目录（小写）
│       ├── api.ts             #   模块 API 封装
│       ├── store.ts           #   模块状态（可选）
│       ├── types.ts           #   模块类型（可选）
│       ├── components/        #   模块私有组件（可选）
│       └── pages/             #   模块页面
│
├── pages/                     # 独立页面（非模块页面，如登录页）
│   └── LoginPage.tsx
│
├── App.tsx                    # 路由配置
└── main.tsx                   # 应用入口
```

## 二、新建模块标准流程

### Step 1：创建模块目录

```
src/modules/{module}/
├── api.ts
├── store.ts          # 可选
├── types.ts          # 可选
├── components/       # 可选
└── pages/
```

### Step 2：定义类型（types.ts）

```typescript
// src/modules/{module}/types.ts

export interface {Entity} {
  id: number
  name: string
  created_at: string
  updated_at: string
}

export interface {Entity}Input {
  name: string
  description?: string
}
```

### Step 3：封装 API（api.ts）

```typescript
// src/modules/{module}/api.ts

import { apiClient } from '@/shared/api'
import type { {Entity}, {Entity}Input, PaginationParams, PaginatedResponse } from '@/shared/types'

export const {module}Api = {
  // 列表查询
  getList: (params: PaginationParams) =>
    apiClient.get<PaginatedResponse<{Entity}>>('/{module}/', { params }),

  // 详情查询
  getById: (id: number) =>
    apiClient.get<{Entity}>(`/{module}/{id}/`),

  // 创建
  create: (data: {Entity}Input) =>
    apiClient.post<{Entity}>('/{module}/', data),

  // 更新
  update: (id: number, data: Partial<{Entity}Input>) =>
    apiClient.put<{Entity}>(`/{module}/{id}/`, data),

  // 删除
  delete: (id: number) =>
    apiClient.delete(`/{module}/{id}/`),
}
```

### Step 4：模块状态（store.ts，可选）

```typescript
// src/modules/{module}/store.ts

import { create } from 'zustand'
import type { {Entity} } from './types'

interface {Module}State {
  // 数据
  list: {Entity}[]
  selected: {Entity} | null

  // 加载状态
  loading: boolean

  // Actions
  setList: (list: {Entity}[]) => void
  setSelected: (item: {Entity} | null) => void
  setLoading: (loading: boolean) => void
}

export const use{Module}Store = create<{Module}State>((set) => ({
  list: [],
  selected: null,
  loading: false,

  setList: (list) => set({ list }),
  setSelected: (selected) => set({ selected }),
  setLoading: (loading) => set({ loading }),
}))
```

### Step 5：编写页面（pages/{Module}Page.tsx）

```typescript
// src/modules/{module}/pages/{Module}Page.tsx

import { useState, useEffect } from 'react'
import { PageLayout } from '@/shared/components'
import type { ActionButton } from '@/shared/components'
import { {module}Api } from '../api'
import type { {Entity} } from '../types'
import {
  Box,
  Table,
  TableBody,
  TableCell,
  TableContainer,
  TableHead,
  TableRow,
  Paper,
  Typography,
  Button,
  IconButton,
  CircularProgress,
} from '@mui/material'
import { Add as AddIcon, Edit as EditIcon, Delete as DeleteIcon } from '@mui/icons-material'

export function {Module}Page() {
  const [data, setData] = useState<{Entity}[]>([])
  const [loading, setLoading] = useState(true)

  // 加载数据
  useEffect(() => {
    loadData()
  }, [])

  const loadData = async () => {
    try {
      setLoading(true)
      const res = await {module}Api.getList({ page: 1, page_size: 20 })
      setData(res.data.results)
    } catch (error) {
      console.error('Failed to load data:', error)
    } finally {
      setLoading(false)
    }
  }

  // 操作按钮
  const actions: ActionButton[] = [
    {
      label: '新建',
      onClick: () => console.log('Create'),
      variant: 'contained',
      startIcon: <AddIcon />,
    },
  ]

  if (loading) {
    return (
      <Box sx={{ display: 'flex', justifyContent: 'center', p: 4 }}>
        <CircularProgress />
      </Box>
    )
  }

  return (
    <PageLayout
      variant="action"
      title="模块管理"
      subtitle={`共 ${data.length} 条记录`}
      actions={actions}
    >
      <TableContainer component={Paper} variant="outlined">
        <Table>
          <TableHead>
            <TableRow>
              <TableCell>ID</TableCell>
              <TableCell>名称</TableCell>
              <TableCell>创建时间</TableCell>
              <TableCell align="right">操作</TableCell>
            </TableRow>
          </TableHead>
          <TableBody>
            {data.map((row) => (
              <TableRow key={row.id}>
                <TableCell>{row.id}</TableCell>
                <TableCell>{row.name}</TableCell>
                <TableCell>{row.created_at}</TableCell>
                <TableCell align="right">
                  <IconButton size="small" color="primary">
                    <EditIcon fontSize="small" />
                  </IconButton>
                  <IconButton size="small" color="error">
                    <DeleteIcon fontSize="small" />
                  </IconButton>
                </TableCell>
              </TableRow>
            ))}
          </TableBody>
        </Table>
      </TableContainer>
    </PageLayout>
  )
}
```

## 三、PageLayout 使用指南

### 布局变体一览

| variant | 适用场景 | 必需 props |
|---------|---------|-----------|
| `simple` | 纯标题页 | `title` |
| `action` | 带操作按钮 | `title`, `actions` |
| `search` | 带搜索框 | `title`, `search` |
| `tab` | 多 Tab 切换 | `title`, `tabs`, `activeTab`, `onTabChange` |
| `stats` | 统计卡片 | `title`, `stats` |

### 各变体用法

#### 1. Simple - 简单标题

```tsx
<PageLayout title="页面标题" subtitle="页面描述">
  {/* 内容区 */}
</PageLayout>
```

#### 2. Action - 带操作按钮

```tsx
const actions: ActionButton[] = [
  {
    label: '新建',
    onClick: handleCreate,
    variant: 'contained',
    startIcon: <AddIcon />,
  },
  {
    label: '导出',
    onClick: handleExport,
    variant: 'outlined',
    startIcon: <DownloadIcon />,
  },
]

<PageLayout
  variant="action"
  title="用户管理"
  subtitle="管理系统用户"
  actions={actions}
>
  {/* 内容区 */}
</PageLayout>
```

#### 3. Search - 带搜索

```tsx
const search: SearchConfig = {
  placeholder: '搜索名称、邮箱...',
  onSearch: (value) => handleSearch(value),
}

<PageLayout
  variant="search"
  title="订单管理"
  subtitle="查看和管理订单"
  search={search}
>
  {/* 内容区 */}
</PageLayout>
```

#### 4. Tab - 多 Tab 切换

```tsx
const tabs = [
  { label: '全部', value: 'all' },
  { label: '进行中', value: 'active' },
  { label: '已完成', value: 'completed' },
]

<PageLayout
  variant="tab"
  title="项目管理"
  tabs={tabs}
  activeTab={activeTab}
  onTabChange={setActiveTab}
>
  {/* 内容区 */}
</PageLayout>
```

#### 5. Stats - 统计卡片

```tsx
const stats: StatItem[] = [
  {
    label: '总用户数',
    value: 1234,
    icon: <PeopleIcon />,
    color: 'primary',
    trend: { value: 12, positive: true },
  },
  {
    label: '活跃用户',
    value: 567,
    icon: <TrendingUpIcon />,
    color: 'success',
  },
]

<PageLayout
  variant="stats"
  title="数据概览"
  stats={stats}
>
  {/* 内容区 */}
</PageLayout>
```

## 五、API 调用规范

### 全局 API Client

```typescript
import { apiClient } from '@/shared/api'

// GET 请求
const res = await apiClient.get<User>('/users/1')

// POST 请求
const res = await apiClient.post<User>('/users/', { name: '张三' })

// PUT 请求
const res = await apiClient.put<User>('/users/1/', { name: '李四' })

// DELETE 请求
await apiClient.delete('/users/1/')
```

### 拦截器说明

- **请求拦截**：自动携带 Bearer Token
- **响应拦截**：401 自动跳转登录页

## 六、状态管理规范

### 全局 Store（shared/stores/）

| Store | 用途 | 状态 |
|-------|------|------|
| `authStore` | 用户认证状态 | token, user, login, logout |
| `layoutStore` | 布局状态 | sidebarOpen, toggleSidebar |

### 模块 Store（modules/{module}/store.ts）

- 仅存放**模块私有状态**
- 跨模块共享状态放全局 store
- 简单模块可不用 store，直接用 useState

### Store 命名规范

```typescript
// 全局：use{Xxx}Store
export const useAuthStore = create(...)
export const useLayoutStore = create(...)

// 模块：use{Module}Store
export const useUserStore = create(...)
```

## 七、类型规范

### 全局类型（shared/types/）

```typescript
// 分页相关
export interface PaginationParams {
  page: number
  page_size: number
  search?: string
}

export interface PaginatedResponse<T> {
  count: number
  next: string | null
  previous: string | null
  results: T[]
}
```

### 模块类型

- 模块私有类型放 `modules/{module}/types.ts`
- 跨模块共享类型放 `shared/types/`

## 八、组件开发规范

### 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 组件文件 | PascalCase | `UserList.tsx` |
| 组件函数 | PascalCase | `export function UserList()` |
| 模块目录 | lowercase | `modules/user/` |
| API 文件 | lowercase | `api.ts` |
| Store 文件 | lowercase + Store | `userStore.ts` |

### 导出规范

```typescript
// 命名导出（推荐）
export function UserList() { ... }

// 统一导出（index.ts）
export { UserList } from './UserList'
export type { User } from './types'
```
